## 分析范围

- 入口：`a_share_brief.drivers.cli.main`（`build` / `view` 两个命令）。
- 追踪边界：入口 → 用例 → 端口 → 适配器/存储/渲染；不含市场数据生成脚本（旧链路）。
- 场景：微观（调用链）+ 宏观（项目文件结构）。

## 代码链路树（微观）

```text
python -m a_share_brief.drivers.cli build|view
└─ 🚪 cli.main(argv)
   ├─ 🚪 argparse 解析 cmd/day/root/verbose
   │  └─ ❌ 参数非法 → argparse 退出码 2
   ├─ 装配 FileRepoAdapter(root)
   ├─ 🚪 分支 cmd=build
   │  └─ core::BuildSnapshot.__call__(day)
   │     ├─ PoolPort.month_top(10) / d60_top(7)
   │     │  └─ ⚠️ P1 由 _EmptyPools 占位返回空列表
   │     ├─ QuotePort.snapshot(codes)
   │     │  └─ ⚠️ P1 由 _EmptyQuotes 占位返回空映射
   │     ├─ 🗄️ SnapshotRepo.load(day) → 读 work/store/briefing-YYYY-MM-DD.json
   │     ├─ 🔄 revision = prev.revision + 1（无 prev 则为 1）
   │     ├─ 🗄️ SnapshotRepo.save(briefing) → 写同名 JSON（原子性待确认）
   │     └─ 📤 返回 Briefing，cli 打印 "snapshot saved: {day}"
   └─ 🚪 分支 cmd=view
      └─ core::BuildView.__call__(day)
         ├─ 🗄️ SnapshotRepo.load(day) → 读 JSON
         │  └─ ❌ 无快照 → SnapshotNotFound(day)
         ├─ BoardRenderer.render(briefing) → HTML 片段
         └─ 📤 打印前 200 字符；异常由 cli 捕获并返回退出码 1

实时/生产链路（P2 规划，未落地）：
JOB:refresh_live ─▶ RefreshLive ─▶ FallbackQuotes(Eastmoney, Tencent) ─▶ live 表
HTTP GET /d/<date> ─▶ BuildView ─▶ PgRepoAdapter.load ─▶ HtmlRendererAdapter.render
```

## 数据与副作用

- 读：`work/store/briefing-{day}.json`，条件 `day` 精确匹配；无缓存层（P1）。
- 写：同一文件整体覆盖，写入内容含 `day/revision/stocks`；**无事务、无原子替换**（P2 由 PG 主键 `(day, revision)` 保证）。
- 外部：`build` 分支的 P1 占位适配器不发请求；`view` 分支不触网。
- 日志：`snapshot saved day=… revision=… stocks=…`；`view failed day=… reason=…`。

## 分支与出口

- 成功：`build` 返回退出码 0；`view` 打印 HTML 片段并返回 0。
- 失败：参数非法 → argparse 退出码 2；快照缺失 → `SnapshotNotFound` → 退出码 1。
- 待补：外部源失败的重试与降级（P2 由 `FallbackQuotes` + `job_run` 落实）。
