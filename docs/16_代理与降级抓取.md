# 代理池与抓取降级

目标：用青果代理降低限流概率，同时保证 3 分钟 IP 存活期只消耗 1 个 IP；API 失败后降级网页抓取。

## 一、分层

```text
domain/services/rate_limit  令牌桶与坏 IP 判定（纯规则，待补）
application/ports           ProxyPort（acquire / report_bad）
infrastructure/qingguo_proxy 青果适配器：170 秒租约内复用
infrastructure/proxy_client  重试 → 退避 → 换 IP → 网页抓取
interfaces/composition      装配到行情/K线/板块适配器
```

## 二、租约规则

| 规则 | 取值 |
| --- | --- |
| IP 存活 | 180 秒（青果口径） |
| 租约复用上限 | **170 秒**，提前续租避免途中过界 |
| 复用粒度 | 每进程 1 个租约，不按请求换 IP |
| 坏 IP 判定 | 连续失败或 429/501 才标记 |
| 密钥 | 只读环境变量 `QG_KEY`，禁止入库与日志 |

## 三、失败处理顺序

```text
1. 缓存命中           → 直接返回
2. 同 IP 退避重试     → 0.5s / 1s（默认 2 次）
3. 仍失败 → 标记坏 IP，换租约重试一次
4. 仍失败 → 降级网页抓取（scraper）
5. 仍失败 → 抛错并计入 failures 指标
```

## 四、代码位置

- `infrastructure/qingguo_proxy.py`：`QingguoProxyPool.acquire()` / `report_bad()`
- `infrastructure/proxy_client.py`：`ProxyHttpClient.get()` / `get_or_scrape()`
- `tests/test_proxy.py`：租约复用、过期轮换、坏 IP、缺密钥、重试、网页降级

## 五、启用方式

```bash
export QG_KEY=你的密钥       # 不入库、不写进脚本
./restart.sh                 # 重启后适配器自动走代理
```

未设置 `QG_KEY` 时 `acquire()` 返回 None，客户端直连，行为与现在一致。

## 六、网页抓取降级

`get_or_scrape(url, scraper)` 在 API 三次尝试后调用 `scraper`。当前只提供接口与单测，
具体解析器（东财行情页 / 腾讯 quote 页面）按目标字段逐个实现，标注「拟定」。
