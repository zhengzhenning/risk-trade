# 前端编码规约（TypeScript + Vue 3）

适用 `web/`。规则优先级：本文件 > `AGENTS.md` 前端条款 > 框架默认实践。

标注：`[自动]` 工具拦截、`[评审]` 人工检查。

## 一、分层与依赖

1. `packages/core` 零框架依赖，禁止 import `vue`、`uni`、DOM API。`[自动]`（eslint 限制）
2. `packages/api` 只做传输与鉴权，不写业务判断。`[评审]`
3. `packages/ui`、`packages/charts` 只做展示，数据由 `core` 视图模型提供。`[评审]`
4. 页面只组装，禁止直接拼接口字段或写业务规则。`[评审]`

## 二、命名

1. 组件 `PascalCase.vue`（`RankMatrix.vue`），组合式函数 `useXxx.ts`。`[自动]`
2. 变量与函数 `camelCase`，类型与接口 `PascalCase`，常量 `UPPER_SNAKE`。`[自动]`
3. 布尔用 `is/has/can/should` 前缀；事件用 `onXxx`，禁止 `handleClick` 这类无对象名。`[评审]`
4. 接口字段保持后端 `snake_case`，本地视图模型再转 `camelCase`，禁止双写。`[评审]`

## 三、类型与数据

1. `strict` + `noUncheckedIndexedAccess` 必须开启，禁用 `any`（确需用 `unknown` + 收窄）。`[自动]`
2. 跨端数据结构只在 `packages/core/src/types.ts` 定义，其他处复用。`[评审]`
3. 接口返回必须判空：`quote`、`alert`、`monitor_end` 都可能为空。`[评审]`
4. 金额、涨跌幅格式化统一走 `core/format.ts`，禁止页面内 `toFixed` 散落。`[评审]`

## 四、组件

1. 单文件组件顺序固定：`<script setup>` → `<template>` → `<style scoped>`。`[自动]`
2. Props 用类型声明（`defineProps<T>()`），禁止运行时数组声明。`[自动]`
3. 一个组件只做一件事；模板嵌套不超过 5 层。`[评审]`
4. 列表必须给稳定 `key`，禁止用数组下标。`[自动]`（vue 规则）
5. 组件不得直接发请求，数据经 props 或组合式函数注入。`[评审]`

## 五、样式与多端适配

1. 颜色、字号、间距只用 `packages/design` 令牌，禁止硬编码色值。`[评审]`
2. 单位统一 `toUnit()`；小程序/APP 用 `rpx`，H5 用 `px`。`[评审]`
3. 触控区域不小于 44px；安全区用 `env(safe-area-inset-*)`。`[评审]`
4. 禁止依赖平台私有 API；跨端差异封装在 `core`。`[评审]`

## 六、状态与实时

1. 全局状态用 Pinia，组件内状态用 `ref/reactive`，不滥用全局。`[评审]`
2. 实时通道统一 `createRealtime()`：H5 用 SSE，小程序/APP 用 WebSocket。`[评审]`
3. 订阅必须在卸载时释放，禁止泄漏连接。`[评审]`
4. 断线重连要退避并保留最后一次快照，不显示空白页。`[评审]`

## 七、错误与日志

1. 请求错误统一在 `api` 层转换，页面只处理可展示文案。`[评审]`
2. 禁止 `console.log` 留在主分支；调试用 `import.meta.env.DEV` 包裹。`[自动]`
3. 错误上报字段：`route`、`code`、`message`，不含用户敏感信息。`[评审]`

## 八、可访问性与性能

1. 图片必须有 `alt`；可点击元素用 `button` 或带 `role`。`[自动]`（eslint a11y 规则）
2. 首屏图表延迟加载，矩阵超过 100 行时虚拟滚动。`[评审]`
3. 小程序主包不超过 2MB；ECharts 按需引入。`[评审]`

## 九、工具门禁

| 检查 | 命令 | 阈值 |
| --- | --- | --- |
| 类型 | `pnpm -C web typecheck`（`tsc --noEmit`） | 0 错误 |
| 静态 | `pnpm -C web lint`（ESLint flat config） | 0 告警 |
| 格式 | `pnpm -C web format:check`（Prettier） | 全部通过 |
| 构建 | `pnpm -C web build:h5` | 成功 |

## 十、正反例

```vue
<!-- 正：类型化 props、令牌、稳定 key -->
<script setup lang="ts">
import { RANK_COLORS } from "@brief/core";
defineProps<{ rows: PoolEntry[][]; dates: string[] }>();
</script>

<template>
  <view v-for="(row, ri) in rows" :key="dates[ri] ?? ri" class="mx-row">
    <text :style="{ color: RANK_COLORS[ri]?.ink }">#{{ ri + 1 }}</text>
  </view>
</template>

<!-- 反：any、硬编码色值、下标 key -->
<script setup>
defineProps(["rows"]);
</script>
<template>
  <div v-for="(r, i) in rows" :key="i" style="color: #b45309">{{ r }}</div>
</template>
```
