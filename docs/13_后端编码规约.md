# 后端编码规约（Python）

适用 `src/a_share_brief/`、`tests/`。规则优先级：本文件 > `AGENTS.md` 通用条款 > 语言通用实践；冲突时以更严格者为准。

每条规则标注检查方式：`[自动]` 工具拦截、`[评审]` 人工检查。

## 一、分层与依赖

1. `domain` 只依赖标准库，禁止 IO、日志、框架 import。`[自动]`
2. `application` 只依赖 `domain` 与标准库；端口定义在此，实现放 `infrastructure`。`[自动]`
3. `infrastructure` 禁止 import `interfaces`；第三方字段名只允许出现在本层。`[自动]`
4. `interfaces` 只做参数解析与装配，不写业务判断。`[评审]`
5. 跨层调用必须经端口，禁止绕过用例直接调适配器。`[评审]`

## 二、命名

1. 类用业务名：`StockQuote`、`PoolRanking`，禁止 `Data`、`Info`、`Manager`、`Helper`。`[评审]`
2. 函数用「动词 + 业务对象」：`build_snapshot`、`cluster_themes`、`exchange_of`。`[评审]`
3. 布尔用 `is_/has_/can_` 前缀；单位写进名称或注释（`amount` 元、`volume` 股）。`[评审]`
4. 常量全大写，领域枚举用 `Enum` 且值可读（`"TRIGGERED"` 而非 `1`）。`[评审]`

## 三、类型与 API

1. 公共函数必须全量类型标注，禁用裸 `Any`。`[评审]`
2. 返回值不使用 `None` 表示「失败」；失败抛异常或返回显式空集合。`[评审]`
3. 聚合根不可变（`frozen=True`），更新返回新实例。`[自动]`（结构测试）
4. 对外接口用 `Protocol` 定义端口，实现类不得反向依赖调用方。`[评审]`

## 四、注释与文档

1. 公共类、公共方法必须多行 docstring，含 `Args`、`Returns`、`Raises`。`[评审]`
2. 注释解释「为什么」与业务约束，禁止逐行翻译代码。`[评审]`
3. 领域规则必须注明来源（交易所规则、口径），便于回溯。`[评审]`
4. 过期注释必须同步删除，禁止保留与代码矛盾的说明。`[评审]`

## 五、错误处理

1. 领域异常定义在 `domain/errors.py`，继承 `DomainError`。`[评审]`
2. 适配器吞掉单条失败并跳过，批次不因一只标的失败中断。`[评审]`
3. 用例失败上抛，由入口层记录并映射退出码或 HTTP 状态。`[评审]`
4. 禁止裸 `except Exception`；确需宽捕获时必须限定异常类型并写明理由。`[自动]`（B/BLE 规则）

## 六、日志

1. 只记关键业务结果与失败原因，禁止用日志替代指标。`[评审]`
2. 字段用可检索键值：`day=`、`codes=`、`reason=`，禁止拼接长句。`[评审]`
3. 禁止输出 token、密钥、完整请求体。`[评审]`
4. 库代码用 `logging.getLogger(__name__)`，禁止 `print`。`[自动]`（ruff T20 可扩展）

## 七、测试

1. 用例测试只用 Fake 端口，不触网、不落盘。`[自动]`（CI 无网络亦可跑）
2. 新增聚合或领域规则必须补测试，覆盖边界与冲突分支。`[评审]`
3. 测试命名描述行为：`test_pool_diff_detects_added_removed_retained`。`[评审]`
4. 禁止在测试里复制实现逻辑做断言。`[评审]`

## 八、工具门禁

| 检查 | 命令 | 阈值 |
| --- | --- | --- |
| 静态检查 | `make lint`（ruff：E/F/I/UP/B/SIM/C4/PT/RET） | 0 告警 |
| 单测 | `make test` | 全绿 |
| 分层与规模 | `tests/test_architecture.py` | 依赖方向 0 违规；文件 ≤160 行、服务 ≤120 行 |
| 领域纯净 | 同上 | `domain/**` 无 IO 依赖 |

## 九、正反例

```python
# 正：业务命名、显式异常、docstring 完整

    """按代码前缀判定上市板块。

    Args:
        code: 6 位证券代码。

    Returns:
        STAR/GEM/BSE/MAIN。

    Raises:
        ValueError: 代码长度不为 6。
    """
    if len(code) != 6:
        raise ValueError(f"非法代码: {code}")
    ...

# 反：无类型、裸异常、名称无业务含义
def process(data):
    try:
        return do(data)
    except Exception:
        return None
```
