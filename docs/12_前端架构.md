# 前端架构

选型：uni-app + Vue 3 + TypeScript，一套业务代码覆盖 H5 / 小程序 / APP；H5 先行。编码约束见 [14_前端编码规约](14_前端编码规约.md)。

## 一、为什么这样分

| 端 | 技术 | 说明 |
| --- | --- | --- |
| H5 | Vite + Vue 3 | 首屏与图表验证，支持 SSR 留待需要时 |
| 小程序 | uni-app（mp-weixin） | 只能编译产物，不能套壳 |
| APP | uni-app（app-plus） | 复用小程序页面，差异只在打包配置 |

关键约束：**小程序不支持 SSE**，实时通道统一抽象，H5 用 SSE、小程序/APP 用 WebSocket。

## 二、目录

```text
web/
├─ apps/
│  ├─ h5/           Vite 入口（首期）
│  ├─ miniapp/      uni-app 页面与 manifest
│  └─ app/          APP 打包说明（复用 miniapp）
├─ packages/
│  ├─ core/         类型、格式化、名次七色、自适应、实时通道
│  ├─ api/          传输抽象与接口定义
│  ├─ charts/       ECharts 选项与分端初始化
│  ├─ ui/           跨端组件（指标卡、股池矩阵）
│  └─ design/       设计令牌（颜色/字号/间距/安全区）
└─ tsconfig.base.json / pnpm-workspace.yaml
```

分层规则：

1. `core` 零框架依赖，可被任何端引用。
2. `api` 只做协议与鉴权，不写业务判断。
3. `ui`/`charts` 只做展示，数据由 `core` 的视图模型提供。
4. 页面只组装，不拼接口字段。

## 四、首屏实测

- 启动：`make api`（:8000）+ `pnpm -C web dev:h5`（:5173/5174）。
- 数据：`/api/briefing` 返回当日快照，页面展示指数卡与月度前七（含榜外 8–10）。
- 已确认：名次七色、涨红跌绿、设计令牌生效、无控制台错误。
- 矩阵：`/api/pool/history?window=MONTH&days=6` 返回跨日行列，已渲染 6 列（11/06–11/13），列宽 rpx、支持横向滚动。
- 题材：历史快照由归档导入（含叙述）；今日实时快照由 F10 行业生成，前 3 个题材再按三级行业板块扩散成员（`SectorPort`）。
- 东财板块接口有频控，扩散失败时只保留锚点，不报错。
- 视图转换放在 `application/views.py`，接口层不再拼装结构。

## 五、多端自适应

| 项 | 方案 |
| --- | --- |
| 单位 | 设计稿 750：小程序/APP 用 `rpx`，H5 用 `px`；`toUnit()` 统一换算 |
| 断点 | 375 / 768 / 1024 / 1440，`columnsOf()` 返回 1/2/4 列 |
| 安全区 | H5 用 `env(safe-area-inset-bottom)`；小程序/APP 由系统注入 |
| 触控 | 可点击行高不低于 44px |
| 深色 | 设计令牌按 `prefers-color-scheme` 切换 |
| 图表 | H5/APP Canvas，小程序 ec-canvas；统一 `ChartSpec` 输入 |

## 六、前后端契约

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/briefing?date=` | GET | 当日快照（指数、股池、题材、个股） |
| `/api/pool/{window}?date=` | GET | 单窗口排名与差异 |
| `/api/alert?codes=` | GET | 异动级别与距离 |
| `/api/live` | SSE / WS | 实时行情增量 |
| `/api/history` | GET | 可选日期与版本 |

约定：

- JSON 字段使用 `snake_case`，与 Python 聚合序列化一致。
- 鉴权用 `Authorization: Bearer <token>`；H5 存内存 + 刷新令牌，小程序用 `uni.storage`。
- H5 由 Caddy 反向代理 `/api` 到 FastAPI，避免跨域；小程序需在后台配置合法域名。
- 所有时间字段为 ISO 8601 字符串，前端只格式化不计算时区。

## 七、构建与发布

| 端 | 命令 | 产物 |
| --- | --- | --- |
| H5 | `pnpm -C web dev:h5` / `build:h5` | 已实测：uni-app H5 构建通过，页面渲染 3 张指数卡 + 10 行股池，涨红跌绿正确 |
| 小程序 | `pnpm -C web/apps/miniapp build:mp-weixin` | 已验证构建通过，产物 `dist/build/mp-weixin` |
| APP | HBuilderX 导入 `apps/miniapp` | 云打包/离线打包 |

## 八、迁移路径

1. 后端补齐 `/api/briefing` 与 `/api/live`，静态页继续服务。
2. H5 先迁「指标卡 + 股池矩阵」，与旧页对照。
3. 小程序复用页面，替换图表与实时适配层。
4. APP 打包，接登录与推送。

## 九、风险

- 图表重写是主要工作量，建议先迁 1 张图验证视觉。
- 小程序包体限制 2MB，ECharts 需按需引入并分包。
- 小程序 WebSocket 后台会挂起，进入页面先拉快照再收增量。
