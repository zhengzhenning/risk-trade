# 动态股池 · 领域设计

## 一、聚合

- `股池排名`：某日某窗口的排名快照，不可变。
- `股池条目`：名次、区间涨跌幅、当日涨跌、换手、竞价、题材。
- `股池差异`：与上一交易日的新进/移出/留存。
- `股池矩阵`：行＝名次、列＝交易日，单元格标「新进」。

## 二、规则

1. 窗口：月度前十（矩阵展示前七，榜外 8–10）、近 60 日前七。
2. 排序用接口序号，不本地重排。
3. 基线取上一不同交易日；同日重跑覆盖当日，不产生新基线。
4. 差异只比前七。
5. 接口返回空视为事实性空：标基线缺失与说明，不写历史库。
6. 幂等键：日期、窗口、名次。

## 三、数据来源

| 数据 | 来源 |
| --- | --- |
| 双窗口排名 | 东财选股器条件接口 |
| 当日涨跌与换手 | 行情接口覆盖 |
| 题材 | F10 行业与题材 |
