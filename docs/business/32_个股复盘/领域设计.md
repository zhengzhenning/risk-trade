# 个股复盘 · 领域设计

## 一、聚合

- `股票`：基础数据 + 行情数据 + 异动数据 + 题材归属。
- `题材`：由股池龙头锚定，带出成员与主升逻辑。
- `个股题材`：题材归属段，支持切换；`题材切换`：切换事件。
- `威科夫阶段`：吸筹/洗盘/启动/派发，附周线验证。

## 二、规则

1. 题材必须回指榜单名次，无锚点不成题材。
2. 以点带面：锚点（前七龙头）→ 成员（同题材跟风/梯队）→ 板块效应。
3. 主升逻辑固定三段：触发 → 扩散 → 卡位，且必须有涨停池/连板/资讯证据。
4. 题材可切换：同日只能一个生效；归属段区间不重叠；新段记录来源；旧段保留。
5. 名字系炒作必须有涨停池同系标的佐证，否则置信度不高于 0.5。
6. 威科夫阶段按规则判定，证据不足标「观察」。

## 三、数据来源

| 数据 | 来源 |
| --- | --- |
| 基础数据 | 选股器与 F10 |
| 行情 | 行情接口（换手、量比、竞价） |
| 异动 | 交易所严重异动接口 |
| 题材证据 | 涨停池与资讯 |

## 四、与其他模块

- 锚点来自 31 动态股池，证据来自 34 要闻溯源，风险来自 33 异动预警。
