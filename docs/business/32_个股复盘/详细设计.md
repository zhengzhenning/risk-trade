# 个股复盘 · 详细设计

## 一、用例

| 用例 | 触发 | 输出 |
| --- | --- | --- |
| 构建个股复盘 | 日终 | 个股聚合（含题材段） |
| 聚类题材 | 与刷新股池同步 | 按锚点名次排序的题材 |
| 判定威科夫 | 15:05 | 阶段与周线验证 |
| 生成主升逻辑 | 15:06 | 触发/扩散/卡位与证据 |

## 二、接口与任务

- `GET /api/stock/{code}`：个股聚合与题材段。
- `JOB: build_stock_review`：cron `0 8 15 ? * MON-FRI`，超时 300 秒，失败重试 3 次。

## 三、数据表

| 实体 | 主键 | 说明 |
| --- | --- | --- |
| STOCK_QUOTE | (code, day) | 日线行情 |
| STOCK_THEME | (code, theme_id, start_day) | 题材归属段 |
| THEME | id | 题材与锚点 |
| VP_PHASE | (code, day) | 阶段判定 |

## 四、约束

- 同日多题材冲突直接拒绝入库。
- 主升逻辑必须附资讯链接与涨停池证据，禁止只写结论。
