# A股每日要闻与强势股池简报

## 定位

一条流水线产出一份当日 HTML 联动看板 `market-briefing-YYYY-MM-DD.html`（默认交付物；Markdown 简报为可选附录）：

1. **要闻**：三渠道采集 → 跨渠道去重 → 按重要性排序 → 判定利好/利空板块
2. **股池**：东财选股器**条件直连接口**（自然语言条件，无需在 UI 保存方案）提取两个方向——方向一·连板情绪（连板=2 且换手>5% 且竞价涨幅>-5%，或 2板断板且涨幅>0）、方向二·月度强势（本月涨幅前十且>20%）；均剔 ST/退市/北交所/创/科板，月度方向另剔新股次新
3. **映射**：要闻 ↔ 池内标的互查（只映射池内，不引池外）；按行业×概念做题材聚类并反查当日要闻

分工原则：**确定性抓取交给脚本，判断型工作（去重、排序、板块判定、题材聚类、映射）由模型执行**。行情数据只认东方财富口径（选股器接口结果自带当日行情与行业/概念列，不依赖 push2 行情接口）。

## 执行流程

### 第 1 步：采集三渠道要闻

```bash
python3 skills/market-daily-briefing/scripts/fetch_news.py --date 2026-09-29 --out <工作目录>
```

产出 `news.json`：东财要闻频道（含文章原文 URL）、新浪财经要闻（roll 接口，分页回溯覆盖全日）、财联社电报（m 站 SSR）。代理配置见 `references/channel-guide.md`（默认直连）。

### 第 2 步：财联社深度·头条（浏览器渲染）

财联社 `depth?id=1000` 页面为 JS 渲染且接口签名未破解，按 `references/channel-guide.md` 的浏览器提取片段，用 `browser-use:control-browser` 打开并提取当日头条（标题、摘要、相对时间、detail 链接），并入要闻池。相对时间换算规则：页面"昨天 HH:MM" = 目标日期前一天的该时刻。

### 第 3 步：提取双方向股池（选股器条件直连接口）

```bash
python3 skills/market-daily-briefing/scripts/fetch_pool_api.py --direction both --out <工作目录>
```

条件文本在脚本 `DIRECTIONS` 中配置（自然语言，接口自动解析；支持"前百分之一/前十/N%"与"YYYY.MM.DD至YYYY.MM.DD"历史区间措辞）。产出 `pool_连板情绪.json`、`pool_月度强势.json`：列随条件自适应（连板方向带连板天数/竞价涨幅/换手率，月度方向带区间涨跌幅/行业二级/概念），中文列名直接可用。注意 `total=0` 多为事实性空（如月初"月涨幅>20%"主板单日上限 10%），不是故障——**方向二空态如实展示，禁止以历史月份数据替代**。接口细节与浏览器渲染兜底路径见 `references/channel-guide.md`。

### 第 3.7 步：提取标的概念（东财 F10 核心题材）

```bash
python3 skills/market-daily-briefing/scripts/fetch_concepts.py --codes <逗号分隔6位代码> --out <工作目录>
```

接口 `emweb.securities.eastmoney.com/PC_HSF10/CoreConception/PageAjax?code=SH/SZ+代码`（无需鉴权）：
`ssbk`=行业层级（前3条）+风格/形态标签；`hxtc`=核心题材要点（`主营业务`/`行业背景` 关键词即产业题材，如传艺科技="钠离子电池业务"）。产出 `concepts.json`，注入看板数据区 `CONCEPTS` 块（个股行仅显示一行"代码 · F10 三级行业"；**主营关键词 chips 不在正文展示**，仅用于题材归组与梯队员悬停归属依据，保持信息简洁）。

### 第 4 步：分析与映射（模型执行，先读规则）

读 `references/mapping-rules.md`，然后：

- 跨渠道去重合并（渠道列合并标注全部命中来源）
- 按重要性排序，取头条级（默认 8 条左右，宁缺毋滥）
- 判定每条新闻的利好/利空板块（板块口径=东财行业二级，与股池一致）
- 板块 → 池内标的映射；池内无匹配标的时板块行标注"股池内无相关行业标的"，**禁止引入池外标的**
- 反向生成两方向股池表"消息面"列（要闻编号 + 方向）
- **题材聚类**：每个方向按行业×概念聚成题材组（如"固态电池×5"），反查当日要闻关联；无命中的组标注"无当日催化（题材轮动/资金驱动）"，必要时用佐证源搜主题帖佐证
- 双池交叉：交集=情绪+趋势共振标的，单池独有=单边信号，写入"题材挖掘"小结

### 第 5 步：产出 HTML 联动看板（默认交付物）

复制 `assets/dashboard-template.html` 为 `market-briefing-YYYY-MM-DD.html`（仓库根目录或用户指定路径），替换文件中"数据注入区"的八个数据块（模板注入区头部附清单注释，标注每块来源步骤）：

- `STOCKS`：双方向股池标的（发酵过程由 TIMELINE 消息序列与 LADDER 天梯呈现）
- `THEMES` / `NEWS`：题材聚类与去重后要闻（NEWS 含渠道原文地址链接）
- `CONCEPTS`：F10 核心题材（第 3.7 步产物：三级行业+主营关键词+风格标签），个股行与题材归组的唯一概念来源——**禁止再用选股器结果表的概念列或凭印象归类**
- `MACRO`：宏观·市场消息时间线（与股池题材无直接映射的市场级消息：货币/海外/风格/地缘等，每条带日期与原文地址，无链接的如实标注）
- `LADDER`：全市场"连板≥2"天梯快照（第 3 步用 fetch_pool_api 另查，含抓取时间），按 F10 概念/行业优先归入题材，池外标标记+悬停归属依据
- `EVENTS`：跨题材关键事件日（数据保留供扩展使用，当前页面无图内标注）
- `TIMELINE`：题材发酵泳道时间线——按"股池确认板块 → 反推题材发酵"组织：每题材的 ★首发消息节点**必须给可点击的原文地址与完整发布时间戳**（财联社电报精确到秒——从 detail 页 ctime 或电报接口取；东财/新浪文章页精确到分——抓文章页发布时间；取不到的如实标注时段），行情确认节点（首板/连板/跌停）以天梯快照或东财行情页事实为依据；窗口外启动的题材标注"窗口外，首发溯源待补"；右端状态徽章按末段走势+消息面判：持续发酵/高位分歧/分化/退潮
- **题材连板天梯**（`LADDER` 数据块）：用选股接口另查全市场"连板大于等于2"快照（含抓取时间），按 **F10 概念/行业（第 3.7 步产物）优先、盘面板块行情兜底** 的顺序归入各题材块呈现**行式连板天梯表**（每行一个板数层级，自上而下板数递减——即从下往上看越高；行结构=N板·N只徽章 + 板数条形（长度∝板数）+ 该层股票 chips 横排，池外标的虚线边框灰字标注），**含同题材池外标的**（灰字+"池外"标记+悬停显示 F10 归属依据，如"传艺科技 池外·F10主营=钠离子电池业务"），无法归组的放"宏观·市场"块的"未归组梯队"；注意梯队快照时间可能与股池/K线快照不同，需各自标注

看板结构（模板已内置，勿改）：**整页按题材分组**——每题材一个完整区块（概览头：状态徽章+题材累计涨幅（时序走势由区块头题材累计涨幅与消息序列时间戳承担） → 连板天梯 → 左栏该题材个股（F10行业+涨跌+竞价换手，名称外链东财行情页）→ 右栏消息序列（每条带日期/来源/原文跳转）→ **标的行情外链**：个股行与连板天梯中的股票名均为外链，指向 `https://quote.eastmoney.com/{sh|sz}{代码}.html`（新窗口打开），行情细节由东财行情页承担。

Markdown 版简报（`references/report-template.md` 格式）为**可选附录**，用户明确要 md 时再产出。Markdown 附录的格式硬约束：

- 池内标的**加粗**（不用下划线）；涨幅 `<font color="red">`、跌幅 `<font color="green">`（含涨跌停字样）
- 标的行统一等距格式：`**名称** ｜ 行业 ｜ 月度 x% ｜ 今日 x%`
- 渠道名必须是链接：文档头链频道页，每条新闻链**原文地址**；无单条链接的（如东财 7×24 电报）链频道页并如实标注
- 股池表在前（含消息面列），要闻在后

## 红线

1. **反幻觉**：每条新闻必须来自 news.json / 采集结果并附真实 URL；禁止生成、补写、改写未出现在采集数据中的新闻；行情数值必须来自选股器接口结果，禁止估算。
2. **降级如实**：单渠道失败在文末"数据质量与口径说明"标注原因，不阻塞整份简报；三渠道全失败则报错终止，不产出半空报告。
3. **不碰 push2、限频选股接口**：禁止对 `push2.eastmoney.com` 做全量分页（会触发 IP 封禁）；选股直连接口（np-tjxg-b）单方向间隔 ≥1s，禁止循环刷条件。
4. **佐证源不入正文**：韭研公社/开盘红/淘股吧只用于题材佐证与交叉验证，不单独成为新闻条目。
5. **盘中口径标注**：盘中执行时股池与行情为快照值，简报标题与口径说明必须标注"盘中版+快照时间"；收盘后应重跑终版。
