# A股每日要闻与强势股池简报

## 定位

一条流水线产出一份当日 HTML 联动看板 `market-briefing-YYYY-MM-DD.html`（默认交付物；Markdown 简报为可选附录）：

1. **要闻**：三渠道采集 → 跨渠道去重 → 按重要性排序 → 判定利好/利空板块；题材启动日早于当日的，按历史回溯补抓消息（≤5 个交易日）
2. **股池**：东财选股器**条件直连接口**（自然语言条件，无需在 UI 保存方案）提取双窗口——方向一·月度前十（矩阵展示前七，榜外区固定展示第 8-10 名）、方向二·近十日三强（近十日涨幅前三，接口原生解析为 10 个交易日区间）；均剔 ST/退市/北交所/创/科板；条件内嵌"竞价涨幅大于-11%"**非过滤性**带出"集合竞价涨跌幅"列（全标的竞价异动数据源）
3. **溯源**：以月度前七为主轴，按 F10 行业×主营聚成题材 → 溯源全市场连板梯队（连板≥2 快照，题材溯源组件）与**题材行情启动的消息时间链**；近十日三强 ∩ 月度前七标 **★最强**；月度前七与上一交易日快照（前十口径取前 7 子集）对比出**每日新进/移除**
4. **映射**：要闻 ↔ 池内标的互查（只映射池内，不引池外）

分工原则：**确定性抓取交给脚本，判断型工作（去重、排序、板块判定、题材聚类、映射、异动标注）由模型执行**。行情数据只认东方财富口径（选股器接口结果自带当日行情，不依赖 push2 行情接口）。

## 执行流程

### 第 1 步：采集三渠道要闻

```bash
python3 skills/market-daily-briefing/scripts/fetch_news.py --date 2026-09-29 --out <工作目录>
```

产出 `news.json`：东财要闻频道（含文章原文 URL）、新浪财经要闻（roll 接口，分页回溯覆盖全日）、财联社电报（m 站 SSR）。代理配置见 `references/channel-guide.md`（默认直连）。

### 第 2 步：财联社深度·头条（浏览器渲染）

财联社 `depth?id=1000` 页面为 JS 渲染且接口签名未破解，按 `references/channel-guide.md` 的浏览器提取片段，用 `browser-use:control-browser` 打开并提取当日头条（标题、摘要、相对时间、detail 链接），并入要闻池。相对时间换算规则：页面"昨天 HH:MM" = 目标日期前一天的该时刻。

### 第 3 步：提取双窗口股池 + 连板天梯（选股器条件直连接口）

```bash
python3 skills/market-daily-briefing/scripts/fetch_pool_api.py --direction all --out <工作目录>
```

产出 `pool_月度前十.json`、`pool_近十日三强.json`、`pool_连板天梯.json`（列随条件自适应，中文列名直接可用：双窗口带区间涨跌幅/集合竞价涨跌幅，天梯带连板(天)）。措辞要点（均已一次性验证，规范见 channel-guide）：

- "近十日涨幅前三"由接口原生解析为 **10 个交易日区间**（回显 `INTERVAL_CHG{起|止|10|天}`），无需换算日期
- 条件末尾"竞价涨幅大于-11%"仅带出"集合竞价涨跌幅"列，**不构成过滤**（主板涨跌停±10%）；**禁止改用"竞价金额大于0元"**（实测会过滤无竞价成交标的，10→9）
- 注意新口径**不剔新股次新**，月度前七可能含次新标的，如实呈现
- 月度前七 total=0 多为事实性空（如月初窗口），**方向一空态如实展示，禁止以历史月份数据替代**

### 第 3.3 步：月度前七当月全景矩阵（快照回补 + 对比）

```bash
python3 skills/market-daily-briefing/scripts/track_month_top10.py --pool <工作目录>/pool_月度前十.json --date 2026-10-14 --out <工作目录>
```

三件事（详见脚本头注释）：

1. 当日快照从 `--pool` 规整入历史库 `archives/pool-history/month-top10.jsonl`（同日重跑覆盖）；
2. **当月逐日回补**：对历史库缺失的当月交易日，用区间措辞（"YYYY.MM.01至YYYY.MM.DD区间涨跌幅前十"）逐日查询补齐——接口自动把区间收敛到实际交易日（国庆等假期自动跳过，有效截止日从 `INTERVAL_CHG{起|止|N|天}` 键读取，单日窗口为 `INTERVAL_CHG{日期}`）。**回补查询不带竞价子句**（集合竞价列对历史区间返回的是最新交易日值，不能当历史当日值，回补快照 auction=null）；接口故障可加 `--no-backfill` 降级，矩阵只呈现已有快照日；
3. 产出 `top10_changes.json`：added/removed/retained（vs 最近一个不同交易日）+ **matrix 全景矩阵视图模型**（dates=当月快照日、labels=MMDD+星期、rankRows=每排名逐日 occupants（rank≤7）、**tailRows=第 8-10 名次行逐日 occupants**（榜外区灰色名次行数据源，不留空）、removed=较昨日移除标的带历史轨迹、tail=当日晚八至十名{rank,code,name,month_pct,last_in7}——旧口径回退数据源，last_in7=退出前七的最后在榜日）.

模型在第 4 步把 F10 题材回填为 `themes`（代码→题材）映射、给 removed 补 `note`（移出原因按当日东财行情页事实可选标注，无依据保持 null）。

### 第 3.3b 步：十日前三当月全景矩阵（快照回补 → D10CHG 块）

```bash
python3 skills/market-daily-briefing/scripts/track_d10_top3.py --pool <工作目录>/pool_近十日三强.json --date 2026-11-04 --out <工作目录>
```

1. 当日快照从 `--pool`（第 3 步"近十日涨幅前三"原生结果）规整入历史库 `archives/pool-history/d10-top3.jsonl`（同日重跑覆盖）；
2. 当月回补：对缺失的当月交易日 D，用区间措辞（"起日至 D 共 10 个交易日区间涨跌幅前三"）重建该时点三强——起点=从 D 往前数第 10 个交易日（交易日序列取月度历史库快照日 ∪ 当月工作日；接口自动收敛节假日，从 `INTERVAL_CHG{起|止|N|天}` 回读校验截止日=D 才采信）。**回补查询不带竞价子句**，间隔 ≥1.2s，已有快照日期禁止重查；
3. 产出 `d10_changes.json`：matrix={dates/labels/rankRows（#1-#3 逐日 occupants，d10_pct=近十日区间涨跌幅）}。themes 与 POOLCHG 共用一份映射。新股（N/C 前缀）可能上榜，如实呈现。

### 第 3.8 步：个股 K 线与板块梯队（量价阶段复盘）

```bash
python3 skills/market-daily-briefing/scripts/fetch_stock_vp.py --codes <前七代码> \
  --out <工作目录> --concepts <工作目录>/concepts.json --bars 120
```

产出 `klines.json`（前复权日K：date/open/close/low/high/量(万手)/涨跌幅/换手）与 `peers.json`（F10 行业对应东财板块成分，按今日涨幅前 15，含跟涨/20cm/北交；渲染时剔除 ST/退市）。板块匹配顺序=主营关键词→F10 三级→二级→一级，语义偏差用 `--map "601599=影视院线"` 覆盖。

**量价阶段判定标准（固化口径，禁止凭感觉）**：

| 阶段 | 硬条件（满足 ≥3 条、且持续 ≥2 个交易日才成立） | 证据字段（写入 `why`） |
|---|---|---|
| 吸筹 | 区间振幅 <15%；量比中位 <1.0×；日均换手 <4%（小盘 <6%）；阳线量 ≥ 阴线量 | 箱体上下沿/振幅、换手区间、量比中位、阳阴量比 |
| 洗盘 | 自高点回撤 8–20%（深洗 ≤25%）；量比中位 <1.1×；不破平台下沿/20 日线 | 回撤幅度、高低点、量比、涨跌停次数 |
| 启动 | 区间涨幅 ≥8%；量比中位 ≥1.2×；≥1 次涨停；放量突破箱体/前高 | 区间涨幅、量比、换手、涨停次数、首板日 |
| 派发 | 量比中位 ≥1.2×；换手峰值 ≥ 日均 1.3×；跌停或区间收跌/长上影 | 区间涨跌、换手均值/峰值、量比、跌停次数 |

证据强度：4 条全满足且 ≥5 日=强；3 条或 2–4 日=中；2 条或单日=弱。

每段同时记录**历时**：`n`=区间内交易日数（卡片显示"N 交易日"），`cal`=自然日天数（悬停）。**周线交叉验证**（klt=102 取 26 周）：启动段要求周收盘>5周线>10周线、近4周>+5%、周量比≥1.2 为"一致"，收于10周线下且近4周<-5% 为"冲突"；吸筹段要求 26 周分位<40%、5/10 周线黏合（差<2%）、周量比<1.2；洗盘段要求收盘≥10周线×0.97、周量比<1.0、近4周下跌；派发段要求分位>70%、周量比≥1.2、本周收阴或上影>3%。命中未达"一致"且无冲突→"部分一致"；冲突条件≥2 条→"冲突"。周线结论必须写明周收盘/5周线/10周线、近4周涨幅、周量比、26周分位与本周上影，随卡渲染 26 周 K 线（含周成交量，平方根刻度，避免单周天量压扁其余周）。
单日派发标 `tent:true`（渲染为"（观察）"）。四阶段可循环。**当前供需只看末段**：吸筹/洗盘/启动→供小于需；派发→供大于需；阶段 <2 日且无涨停/跌停→"无法判定"（如实标注，不硬给结论）。每张卡必须同时渲染"当前供需 + 证据强度 + 逐段依据"，不得只写结论。

### 第 3.9 步：题材启动日消息回溯补抓

## 红线

1. **反幻觉**：每条新闻必须来自 news.json / 采集结果并附真实 URL；禁止生成、补写、改写未出现在采集数据中的新闻；行情数值必须来自选股器接口结果，禁止估算。
2. **降级如实**：单渠道失败在**会话交付回复**中标注原因（看板页面不呈现数据质量说明文字，见版面硬规则），不阻塞整份简报；三渠道全失败则报错终止，不产出半空报告。月度前七 total=0 属事实性空，如实留空且**不写历史库**。
3. **不碰 push2、限频选股接口**：禁止对 `push2.eastmoney.com` 做全量分页（会触发 IP 封禁）；选股直连接口（np-tjxg-b）单方向间隔 ≥1s，禁止循环刷条件。**禁止把"竞价金额大于0元"等会实际过滤标的的条件加进股池措辞**（实测 total 10→9）；竞价列只能用非过滤性的"竞价涨幅大于-11%"带出。第 3.3 步回补只查历史库缺失的当月交易日（间隔 ≥1.2s，已有快照的日期禁止重查）。
4. **佐证源不入正文**：韭研公社/开盘红/淘股吧只用于题材佐证与交叉验证，不单独成为新闻条目。
5. **盘中口径标注**：盘中执行时股池与行情为快照值，简报标题与口径说明必须标注"盘中版+快照时间"；收盘后应重跑终版（重跑时第 3.3 步同日覆盖历史库快照）。
6. **警示须证据**：先涨停后消息（抢跑）警示必须给出"首板日（K线/天梯事实）vs 首发时间戳（原文地址）"证据对，不得凭印象挂警示；确定性抢跑题材不得漏挂。
7. **历史库只存原始**：`archives/pool-history/month-top10.jsonl` 只允许 track_month_top10.py 写入接口原始结果，`archives/pool-history/d10-top3.jsonl` 只允许 track_d10_top3.py 写入，禁止手工补写、修改或删除历史快照；对比基线必须是最近一个**不同交易日**。
8. **ETF 申赎接口限额与口径**：datacenter ETF 报表每日共 ≤10 次调用（aggregate 1＋六类榜单 ~7 含翻页＋单只兜底 ≤2，间隔 ≥1s；push2 clist 4 页＋债基规模单点兜底、push2his 日 K ≤10 次为轻量白名单）；净流入=估算口径且 **T-1 更新**，看板必须标注“数据截至 T-1”；`etf-flow.jsonl` 与月度股池历史库同规则——仅由 `fetch_etf_flow.py` 写入，禁止手工补写。
