# A股每日要闻与强势股池简报

## 定位

一条流水线产出一份当日 HTML 联动看板 `market-briefing-YYYY-MM-DD.html`（默认交付物；Markdown 简报为可选附录）：

1. **要闻**：三渠道采集 → 跨渠道去重 → 按重要性排序 → 判定利好/利空板块；题材启动日早于当日的，按历史回溯补抓消息（≤5 个交易日）
2. **股池**：东财选股器**条件直连接口**（自然语言条件，无需在 UI 保存方案）提取双窗口——方向一·月度前七（本月涨幅前七，7 只以彩虹色系区分）、方向二·近十日三强（近十日涨幅前三，接口原生解析为 10 个交易日区间）；均剔 ST/退市/北交所/创/科板；条件内嵌"竞价涨幅大于-11%"**非过滤性**带出"集合竞价涨跌幅"列（全标的竞价异动数据源）
3. **溯源**：以月度前七为主轴，按 F10 行业×主营聚成题材 → 溯源全市场连板梯队（连板≥2 快照，题材溯源组件）与**题材行情启动的消息时间链**；近十日三强 ∩ 月度前七标 **★最强**；月度前七与上一交易日快照（前十口径取前 7 子集）对比出**每日新进/移除**
4. **映射**：要闻 ↔ 池内标的互查（只映射池内，不引池外）

分工原则：**确定性抓取交给脚本，判断型工作（去重、排序、板块判定、题材聚类、映射、异动标注）由模型执行**。行情数据只认东方财富口径（选股器接口结果自带当日行情，不依赖 push2 行情接口）。

## 执行流程

### 第 1 步：采集三渠道要闻

```bash
python3 skills/market-daily-briefing/scripts/fetch_news.py --date 2026-09-29 --out <工作目录>
```

产出 `news.json`：东财要闻频道（含文章原文 URL）、新浪财经要闻（roll 接口，分页回溯覆盖全日）、财联社电报（m 站 SSR）。代理配置见 `references/channel-guide.md`（默认直连）。

### 第 2 步：财联社深度·头条（浏览器渲染）

财联社 `depth?id=1000` 页面为 JS 渲染且接口签名未破解，按 `references/channel-guide.md` 的浏览器提取片段，用 `browser-use:control-browser` 打开并提取当日头条（标题、摘要、相对时间、detail 链接），并入要闻池。相对时间换算规则：页面"昨天 HH:MM" = 目标日期前一天的该时刻。

### 第 3 步：提取双窗口股池 + 连板天梯（选股器条件直连接口）

```bash
python3 skills/market-daily-briefing/scripts/fetch_pool_api.py --direction all --out <工作目录>
```

产出 `pool_月度前七.json`、`pool_近十日三强.json`、`pool_连板天梯.json`（列随条件自适应，中文列名直接可用：双窗口带区间涨跌幅/集合竞价涨跌幅，天梯带连板(天)）。措辞要点（均已一次性验证，规范见 channel-guide）：

- "近十日涨幅前三"由接口原生解析为 **10 个交易日区间**（回显 `INTERVAL_CHG{起|止|10|天}`），无需换算日期
- 条件末尾"竞价涨幅大于-11%"仅带出"集合竞价涨跌幅"列，**不构成过滤**（主板涨跌停±10%）；**禁止改用"竞价金额大于0元"**（实测会过滤无竞价成交标的，10→9）
- 注意新口径**不剔新股次新**，月度前七可能含次新标的，如实呈现
- 月度前七 total=0 多为事实性空（如月初窗口），**方向一空态如实展示，禁止以历史月份数据替代**

### 第 3.3 步：月度前七当月全景矩阵（快照回补 + 对比）

```bash
python3 skills/market-daily-briefing/scripts/track_month_top10.py --pool <工作目录>/pool_月度前七.json --date 2026-10-14 --out <工作目录>
```

三件事（详见脚本头注释）：

1. 当日快照从 `--pool` 规整入历史库 `archives/pool-history/month-top10.jsonl`（同日重跑覆盖）；
2. **当月逐日回补**：对历史库缺失的当月交易日，用区间措辞（"YYYY.MM.01至YYYY.MM.DD区间涨跌幅前十"）逐日查询补齐——接口自动把区间收敛到实际交易日（国庆等假期自动跳过，有效截止日从 `INTERVAL_CHG{起|止|N|天}` 键读取，单日窗口为 `INTERVAL_CHG{日期}`）。**回补查询不带竞价子句**（集合竞价列对历史区间返回的是最新交易日值，不能当历史当日值，回补快照 auction=null）；接口故障可加 `--no-backfill` 降级，矩阵只呈现已有快照日；
3. 产出 `top10_changes.json`：added/removed/retained（vs 最近一个不同交易日）+ **matrix 全景矩阵视图模型**（dates=当月快照日、labels=MMDD+星期、rankRows=每排名逐日 occupants、removed=较昨日移除标的带历史轨迹）。

模型在第 4 步把 F10 题材回填为 `themes`（代码→题材）映射、给 removed 补 `note`（移出原因按当日东财行情页事实可选标注，无依据保持 null）。

### 第 3.7 步：提取标的概念（东财 F10 核心题材）

```bash
python3 skills/market-daily-briefing/scripts/fetch_concepts.py --codes <逗号分隔6位代码> --out <工作目录>
```

接口 `emweb.securities.eastmoney.com/PC_HSF10/CoreConception/PageAjax?code=SH/SZ+代码`（无需鉴权）：
`ssbk`=行业层级（前3条）+风格/形态标签；`hxtc`=核心题材要点（`主营业务`/`行业背景` 关键词即产业题材，如传艺科技="钠离子电池业务"）。产出 `concepts.json`，注入看板数据区 `CONCEPTS` 块（个股行仅显示一行"代码 · F10 三级行业"；**主营关键词 chips 不在正文展示**，仅用于题材归组与梯队员悬停归属依据，保持信息简洁）。

### 第 3.9 步：题材启动日消息回溯补抓

模型按月度前七的题材归组与首板日（K 线/天梯事实）确定各题材启动日后，对**启动日早于当日**的题材，用 `fetch_news.py --date <启动日前一日起逐日>` 回溯补抓（**≤5 个交易日**，注意限频），历史消息并入 TIMELINE 溯源（★首发节点必须可溯源到原文地址与时间戳）。超出回溯预算或仍无源可考的题材，维持"窗口外，首发溯源待补"标注，不得虚构时间链。

### 第 4 步：分析与映射（模型执行，先读规则）

读 `references/mapping-rules.md`，然后：

- 跨渠道去重合并（渠道列合并标注全部命中来源）
- 按重要性排序，取头条级（默认 8 条左右，宁缺毋滥）
- 判定每条新闻的利好/利空板块（板块口径=东财行业二级，与 F10 一致）
- 板块 → 池内标的映射；池内无匹配标的时板块行标注"股池内无相关行业标的"，**禁止引入池外标的**
- 反向生成两窗口股池表"消息面"列（要闻编号 + 方向）
- **题材聚类（锚定=当日前七）**：题材区块**以当日前七所属题材为出发点**（按前七名次排序成块，非前七标的不再单独成块、仅在矩阵与强势榜可见）；块内梳理**整个题材的标的梯队**——锚定股（彩虹名次签）+ 同题材池外梯队员（`out:true` 灰字+池外签+悬停归属依据，行情取天梯快照）+ 连板天梯行，并在 TIMELINE 加"梯队"节点说明梯队结构（独苗/双龙头/断层等）；消息序列按"窗口外启动 → 行情节点 → 当日消息（时间戳+原文）"组织；无当日催化命中的组标注"无当日催化（题材轮动/资金驱动）"，必要时用佐证源搜主题帖佐证
- **★最强判定**：近十日三强 ∩ 月度前七 → `top:true`（金色★最强徽章，双窗口确认）；仅 d10=近十日新启动；仅 month=月度趋势延续，写入"题材挖掘"小结
- **竞价异动标注**：按 mapping-rules 第 8 节阈值（|集合竞价涨跌幅|≥3%）标注高开/低开异动；数据缺失如实标"—"，禁止估算
- **月度前七矩阵回填**：把 F10 题材整理为 `themes`（代码→题材）映射注入 POOLCHG；给 removed 条目补 `note`（被反超/涨幅回落，按当日东财行情页事实可选标注，无依据保持 null）
- **先涨停后消息判定（高风险警示）**：题材★首发消息时间戳晚于标的首板涨停日的，按 `references/mapping-rules.md` 第 7 节判"抢跑"并双层警示（题材徽章 + 个股 chip，必须附首板日 vs 首发时间戳证据对）；盘前/盘中消息驱动、首发溯源待补、时序不可核的不判

### 第 5 步：产出 HTML 联动看板（默认交付物）

复制 `assets/dashboard-template.html` 为 `market-briefing-YYYY-MM-DD.html`（仓库根目录或用户指定路径），替换文件中"数据注入区"的九个数据块（模板注入区头部附清单注释，标注每块来源步骤）：

- `STOCKS`：双窗口股池标的，字段 `pool`（month｜d10）、`top`（★最强=月度前七∩近十日前三）、`rk`（本月名次 1–7，驱动标的彩虹色分配：#1 红→#7 紫，个股行名称与矩阵字体同色）、`jj`（集合竞价涨跌幅，|值|≥3% 自动高亮+"竞价异动"角标）、`hs`/`pct`（换手/今日涨幅）、`out`（可选，同题材池外梯队员：灰字+池外签+`via` 悬停归属依据，行情字段取天梯快照）、`risk`/`riskNote`（抢跑警示，悬停显示首板日 vs 首发时间证据对）
- `POOLCHG`：月度前七当月全景矩阵——**表头=当月交易日（MMDD+星期，今日列高亮）、行=排名#1–#7；**配色三层信号：题材=实心色签（同题材同色，白字）+左侧 3px 题材色条；名次=当前前七标的按今日名次固定彩虹字（#1 红→#7 紫，跨列同色）+极浅题材底；层级=其余历史格与移除行白底灰字+幽灵色签（描边）**；单元格=标的（外链行情页）+题材色签+月度涨幅**，今日列新进标的带"新"角标；**表尾灰色行=较昨日移除标的**（历史轨迹格 + 今日格"今日移除"标记 + 移出原因注）。数据=第 3.3 步 `top10_changes.json` 的 matrix 字段 + 第 4 步 themes/note 回填；baseline=true 时单列呈现并标"首次记录，无对比基线"
- `THEMES` / `NEWS`：题材聚类与去重后要闻（NEWS 含渠道原文地址链接）
- `CONCEPTS`：F10 核心题材（第 3.7 步产物：三级行业+主营关键词+风格标签），个股行与题材归组的唯一概念来源——**禁止再用选股器结果表的概念列或凭印象归类**
- `MACRO`：宏观·市场消息时间线（与股池题材无直接映射的市场级消息：货币/海外/风格/地缘等，每条带日期与原文地址，无链接的如实标注）
- `LADDER`：全市场"连板≥2"天梯快照（第 3 步 fetch_pool_api 另查，含抓取时间），归组主轴=**月度前七的 F10 题材集合**，池外标标记+悬停归属依据
- `EVENTS`：跨题材关键事件日（数据保留供扩展使用，当前页面无图内标注）
- `TIMELINE`：题材行情启动消息时间链——按"月度前七确认题材 → 反推消息发酵"组织：每题材的 ★首发消息节点**必须给可点击的原文地址与完整发布时间戳**（财联社电报精确到秒——从 detail 页 ctime 或电报接口取；东财/新浪文章页精确到分——抓文章页发布时间；取不到的如实标注时段），行情确认节点（首板/连板/跌停）以天梯快照或东财行情页事实为依据；窗口外启动的题材优先走第 3.9 步回溯补抓，仍无源的标注"窗口外，首发溯源待补"；右端状态徽章按末段走势+消息面判：持续发酵/高位分歧/分化/退潮；先涨停后消息的题材在块头加"⚠ 消息滞后·资金抢跑"红色徽章（TIMELINE `risk`/`riskNote` 字段，★首发节点加"消息晚于首板"红标，判定规则见 mapping-rules 第 7 节）
- **题材连板天梯**（`LADDER` 数据块）：呈现**行式连板天梯表**（每行一个板数层级，自上而下板数递减——即从下往上看越高；行结构=N板·N只徽章 + 板数条形（长度∝板数）+ 该层股票 chips 横排，池外标的虚线边框灰字标注），**含同题材池外标的**（灰字+"池外"标记+悬停显示 F10 归属依据，如"传艺科技 池外·F10主营=钠离子电池业务"），无法归组的放"宏观·市场"块的"未归组梯队"；注意梯队快照时间可能与股池快照不同，需各自标注

看板结构（模板已内置：★最强金色徽章、前七彩虹名次色（个股行 `rk` 徽章与矩阵字体同色）、题材色签+左色条三层信号、全池竞价列+异动高亮、POOLCHG 当月全景矩阵、点击格子联动高亮同一标的并弱化未命中格）：**整页按题材分组**——页首月度前七进出表 → 每题材一个完整区块（概览头：状态徽章+题材累计涨幅 → 连板天梯 → 左栏该题材个股（F10行业+涨跌+竞价+换手，名称外链东财行情页）→ 右栏消息序列（每条带日期/来源/原文跳转））→ **标的行情外链**：个股行与连板天梯中的股票名均为外链，指向 `https://quote.eastmoney.com/{sh|sz}{代码}.html`（新窗口打开），行情细节由东财行情页承担。

Markdown 版简报（`references/report-template.md` 格式）为**可选附录**，用户明确要 md 时再产出。Markdown 附录的格式硬约束：

- 池内标的**加粗**（不用下划线）；涨幅 `<font color="red">`、跌幅 `<font color="green">`（含涨跌停字样）
- 标的行统一等距格式：`**名称** ｜ 行业 ｜ 月度 x% ｜ 今日 x% ｜ 竞价 x%`
- 渠道名必须是链接：文档头链频道页，每条新闻链**原文地址**；无单条链接的（如东财 7×24 电报）链频道页并如实标注
- 股池表在前（含竞价/异动/消息面列），要闻在后

## 红线

1. **反幻觉**：每条新闻必须来自 news.json / 采集结果并附真实 URL；禁止生成、补写、改写未出现在采集数据中的新闻；行情数值必须来自选股器接口结果，禁止估算。
2. **降级如实**：单渠道失败在文末"数据质量与口径说明"标注原因，不阻塞整份简报；三渠道全失败则报错终止，不产出半空报告。月度前七 total=0 属事实性空，如实留空且**不写历史库**。
3. **不碰 push2、限频选股接口**：禁止对 `push2.eastmoney.com` 做全量分页（会触发 IP 封禁）；选股直连接口（np-tjxg-b）单方向间隔 ≥1s，禁止循环刷条件。**禁止把"竞价金额大于0元"等会实际过滤标的的条件加进股池措辞**（实测 total 10→9）；竞价列只能用非过滤性的"竞价涨幅大于-11%"带出。第 3.3 步回补只查历史库缺失的当月交易日（间隔 ≥1.2s，已有快照的日期禁止重查）。
4. **佐证源不入正文**：韭研公社/开盘红/淘股吧只用于题材佐证与交叉验证，不单独成为新闻条目。
5. **盘中口径标注**：盘中执行时股池与行情为快照值，简报标题与口径说明必须标注"盘中版+快照时间"；收盘后应重跑终版（重跑时第 3.3 步同日覆盖历史库快照）。
6. **警示须证据**：先涨停后消息（抢跑）警示必须给出"首板日（K线/天梯事实）vs 首发时间戳（原文地址）"证据对，不得凭印象挂警示；确定性抢跑题材不得漏挂。
7. **历史库只存原始**：`archives/pool-history/month-top10.jsonl` 只允许 track_month_top10.py 写入接口原始结果，禁止手工补写、修改或删除历史快照；对比基线必须是最近一个**不同交易日**。
