# 简报模板与格式规范（Markdown 可选附录）

> **默认交付物为 HTML 联动看板**：复制 `assets/dashboard-template.html` 并替换其中"数据注入区"（九个数据块：STOCKS/POOLCHG/THEMES/NEWS/EVENTS/TIMELINE/CONCEPTS/MACRO/LADDER），含月度前七当月全景矩阵（题材色签+前七彩虹名次色）、前七锚定题材区块（标的梯队+消息序列）、连板天梯、★最强徽章与竞价异动高亮。本文件仅规范 Markdown 附录的格式。

## 格式硬约束（渲染验证过的结论，勿改）

1. **池内标的加粗**（`**名称**`），**不用下划线**（多数渲染器不支持且用户已否决）。
2. 涨跌配色用 `<font color="red">` / `<font color="green">`（比 `style="color:..."` 兼容性好）：**涨幅红色、跌幅绿色**，涨跌停字样随色。
3. 标的行等距同构：`**名称** ｜ 行业 ｜ 月度 +xx.x% ｜ 今日 +xx.xx% ｜ 竞价 +x.xx%`，全角竖线 `｜` 两侧各一空格；竞价 |值|≥3% 时后缀 `（高开异动）/（低开异动）`（阈值见 mapping-rules 第 8 节）。
4. 头部元信息与说明性文字一律逐行列表（markdown 相邻行会粘连成段）。
5. 渠道名必须是 markdown 链接：文档头链频道页，新闻条目链原文地址。
6. 结构固定：**一、股票池（表+变动表+归类小结）在前；二、要闻汇总在后**。
7. **抢跑警示（先涨停后消息）**：按 `mapping-rules.md` 第 7 节判定的题材/标的，在题材挖掘行的题材名后、股池表标的名称后加 `⚠ 先涨停后消息（提前 N 个交易日）·疑似资金抢跑`；头部图例补 `⚠=先涨停后消息·高风险`。判定必须附首板日 vs 首发时间戳证据对。
8. **★最强标识**：近十日三强 ∩ 月度前七的标的，名称后加 `★最强`；头部图例补 `★=最强（月度前七∩近十日前三）`。

# 一、股池

## 方向一·月度强势前七（共 7 只）
- **条件**：本月涨幅前七；剔 ST/退市/北交所/创/科板（不剔新股次新，次新可能上榜）
- 表列：# ｜ 代码 ｜ 名称 ｜ 行业 ｜ 本月涨幅 ｜ 今日涨幅 ｜ 竞价涨幅 ｜ 消息面

## 方向二·近十日三强（共 3 只）
- **条件**：近十日涨幅前三（10 个交易日区间）；剔除同上
- 表列：# ｜ 代码 ｜ 名称 ｜ 行业 ｜ 近十日涨幅 ｜ 今日涨幅 ｜ 竞价涨幅 ｜ 消息面
- 在月度前七内的标的名称后加 **★最强**

## 月度前七当月全景（看板矩阵的 Markdown 简版）
- 完整矩阵（列=当月交易日 MMDD+星期、行=排名、单元格=标的+题材+月度涨幅、表尾移除行）仅在看板呈现；md 附录给简版：
- 逐日前七列表：`MMDD+星期：**#名次 标的A**（题材·月度x%）→ …` 每交易日一行（可按需截取近 5 个交易日）
- **较昨日移除**：一行列明移除标的（昨日排名+题材+移出原因，无依据标"—"）
- **较昨日新进**：一行列明新进标的（今日排名+题材+竞价异动）
- 首次运行标"首次记录，无对比基线"

## 题材挖掘（题材溯源小结）
- 每个题材组一行：**题材名×N**（#编号…）→ 连板梯队概览（最高板数×只数）→ ★首发消息（时间戳+链接） → 关联新闻编号 → 一句话逻辑
- **双窗交叉**：★最强标的单列一行重点标注；仅近十日=新启动，仅月度=趋势延续

## 渠道链接取值规则

| 场景 | 链接指向 |
|---|---|
| 东财频道页要闻 | 该条文章 URL（`finance.eastmoney.com/a/<id>.html`） |
| 东财 7×24 快讯 | 无单条 URL → 链 `https://kuaixun.eastmoney.com/` 并如实标注 |
| 财联社头条/电报 | `https://www.cls.cn/detail/<id>` |
| 新浪 roll 要闻 | 该条文章 URL（json 的 `url` 字段） |
| 一条新闻多来源 | 每个渠道名单独链接；同渠道两条来源分别给链接 |
