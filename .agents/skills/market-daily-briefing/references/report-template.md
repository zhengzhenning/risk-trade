# 简报模板与格式规范（Markdown 可选附录）

> **默认交付物已改为 HTML 联动看板**：复制 `assets/dashboard-template.html` 并替换其中"数据注入区"（STOCKS/THEMES/NEWS/KLINES/EVENTS），含题材分簇联动图、题材时序×事件竖带、个股 K 线启动节点与三栏联动。本文件仅规范 Markdown 附录的格式。

## 格式硬约束（渲染验证过的结论，勿改）

1. **池内标的加粗**（`**名称**`），**不用下划线**（多数渲染器不支持且用户已否决）。
2. 涨跌配色用 `<font color="red">` / `<font color="green">`（比 `style="color:..."` 兼容性好）：**涨幅红色、跌幅绿色**，涨跌停字样随色。
3. 标的行等距同构：`**名称** ｜ 行业 ｜ 月度 +xx.x% ｜ 今日 +xx.xx%`，全角竖线 `｜` 两侧各一空格。
4. 头部元信息与说明性文字一律逐行列表（markdown 相邻行会粘连成段）。
5. 渠道名必须是 markdown 链接：文档头链频道页，新闻条目链原文地址。
6. 结构固定：**一、股票池（表+归类小结）在前；二、要闻汇总在后**。

## 模板骨架（双方向版）

```markdown
# A股每日要闻与强势股池简报（盘中版/终版）

- **日期**：YYYY-MM-DD（周X）
- **数据口径**：东方财富（股池=选股器条件直连接口：方向一连板情绪 / 方向二月度强势）
- **生成时间**：YYYY-MM-DD HH:MM（盘中版必须标注快照时间）
- **要闻渠道**：[东方财富（要闻频道）](https://finance.eastmoney.com/a/czqyw.html) ｜ [财联社（深度·头条）](https://www.cls.cn/depth?id=1000) ｜ [新浪财经（财经要闻）](https://finance.sina.com.cn/topnews/)
- **免责声明**：仅供个人研究，不构成投资建议。
- **图例**：**加粗**=股池内标的 ｜ <font color="red">红色=涨幅</font> ｜ <font color="green">绿色=跌幅</font>

---

# 一、股池

## 方向一·连板情绪（共 N 只）
- **条件**：连板=2 且换手率>5% 且竞价涨幅>-5%；或 2板断板且涨幅>0；剔 ST/退市/北交所/创/科
- 表列：# ｜ 代码 ｜ 名称 ｜ 行业 ｜ 连板(天) ｜ 竞价涨幅 ｜ 换手率 ｜ 今日涨幅 ｜ 消息面
- 断板回封的标的在"连板(天)"列标 0 并加注（如"断板回封"）

## 方向二·月度强势（共 N 只）
- **条件**：本月涨幅前十且>20%；剔 ST/退市/北交所/创/科/新股次新（窗口=YYYY.MM.DD–DD，交易日不足需注明）
- 表列：# ｜ 代码 ｜ 名称 ｜ 行业 ｜ 本月涨幅 ｜ 今日涨幅 ｜ 消息面

## 题材挖掘（分方向）
- 每个题材组一行：**题材名×N**（#编号…）→ 关联新闻编号 → 一句话逻辑；无催化组标"无当日催化"
- **双池交叉**：交集标的（情绪+趋势共振）单列一行重点标注

---

# 二、要闻汇总（去重后 8 条，按重要性排序）

（条目格式同前版：新闻编号加粗标题 / 时间 / 渠道链接 / 利好板块→标的行 / 利空板块）

---

## 数据质量与口径说明
（含：两方向股池各自 total 与空窗口说明、盘中快照时间、渠道成败）
```

## 渠道链接取值规则

| 场景 | 链接指向 |
|---|---|
| 东财频道页要闻 | 该条文章 URL（`finance.eastmoney.com/a/<id>.html`） |
| 东财 7×24 快讯 | 无单条 URL → 链 `https://kuaixun.eastmoney.com/` 并如实标注 |
| 财联社头条/电报 | `https://www.cls.cn/detail/<id>` |
| 新浪 roll 要闻 | 该条文章 URL（json 的 `url` 字段） |
| 一条新闻多来源 | 每个渠道名单独链接；同渠道两条来源分别给链接 |
