# 去重、排序、板块判定与股池映射规则

## 0. 双方向股池与题材挖掘

- **方向一·连板情绪**（连板=2 且换手>5% 且竞价>-5%，或 2板断板且涨幅>0）：短线情绪/打板接力视角。断板组重点看回封（连板=0 但今日涨停=断板回封）。盘中字段（竞价/换手）变化大，必须标注快照时间。
- **方向二·月度强势**（本月涨幅前十且>20%）：趋势视角。月初窗口交易日不足时 total=0 属事实性空，**如实留空并以空态说明呈现，禁止用历史区间（如上一月）数据替代或补凑**。
- **题材聚类**：每个方向内按 行业（东财二级）×概念 聚成题材组（如"固态电池×5""油运×3"），组名取行业或核心概念。
- **新闻反查**：题材组关键词匹配当日要闻池（行业词+概念词），命中则关联新闻编号；无命中的组标注"无当日催化（题材轮动/资金驱动）"，可降级用韭研公社/开盘红搜主题帖佐证。
- **双池交叉**：两方向交集=情绪+趋势共振标的（最高关注级）；仅方向一=纯情绪题材；仅方向二=趋势延续无短线催化。

## 1. 跨渠道去重

- 同一事件的判据：标题实体重叠（主体+动作）或指向同一政策/数据发布。
- 合并后：标题取信息最全的一条；渠道列合并标注全部命中来源；时间取最早。
- 同一事件同渠道的跟踪报道（如"30年美债升至5.595%"→"5.60%"）合并为一条，取最新数值。

## 2. 重要性排序（决定是否入简报、排第几）

事件层级从高到低：

1. 部委/国务院政策与官方发布（贴息、PSL、产业规划、部委发布会）
2. 宏观要闻（国内外大政策、贸易摩擦官方回应）
3. 行业级事件（行业规划落地、海外龙头大动作映射到 A 股行业）
4. 市场整体信号（指数、地量、板块大涨大跌）
5. 公司公告（控制权变更、大额定增/并购）

目标条数：**8 条左右，宁缺毋滥**（用户明确要求"只要重要的"）。海外纯行情/个股异动默认不入选，除非构成行业映射（如英伟达回购→PCB 链）。

## 3. 利好/利空板块判定

- 板块口径 = **东财行业二级**（与选股器结果表 `industry` 列一致），可附概念（如 元件·PCB、元件·光通信模块概念）。
- 判定依据写进板块行括号（一句因果），例：`券商（地量压制经纪与两融收入）`。
- 不是每条新闻都双向：无明确利空就写 `——`，不要硬凑。
- 判定要能落到池内标的才算"有效映射"，否则板块行标注`（股池内无相关行业标的）`。

## 4. 板块 → 池内标的映射

- **只映射池内标的**（pool.json 里的 29/30 只），禁止引入池外股票。
- 匹配顺序：新闻板块 == 标的行业二级 → 命中；其次标的 concepts 含相关概念词（PCB、光通信模块、AI 等）→ 命中并注明概念。
- 每个板块最多列 5 只，按本月涨幅降序。
- 标的行情格式固定：`**名称** ｜ 行业 ｜ 月度 +xx.x% ｜ 今日 +xx.xx%`（数值来自选股器结果表，两位小数可保留一位简写）。

## 5. 消息面反向标注（股池表）

- 股池表"消息面"列：`<编号>·利好/利空（简注）`，如 `H·利好（PCB）`、`A·利好、D·利好（房贷贴息/地产大涨）`。
- 无关联标的写 `—`。
- 文末统计重叠度：`N 只中 M 只有当日消息面关联，其余为月度趋势延续、无当日催化`。

## 6. 官方性红线

- 三渠道均为 L2 权威媒体，正文只收 L2 及其转述的 L1 官方内容。
- 佐证源（韭研公社/开盘红）提升的条目必须在渠道行括号注明"开盘红、韭研公社热帖交叉佐证"。
- 每条新闻必须带真实采集到的原文 URL；禁止出现无出处的新闻。

## 7. 先涨停后消息（抢跑）高风险警示

部分标的在题材首发消息公布**之前**就已涨停（实例：2026-09 房地产——深物业A 9/28 首板，贴息政策 9/29 18:07 才发布）。资金先于消息抢跑，疑似消息提前泄露/知情资金进场，消息落地后利好兑现风险高，必须显式警示。

**判定（题材级 + 个股级，覆盖池内标的与天梯梯队员）：**

- 对照对象：该题材标的的**首板涨停日**（K 线/天梯/东财行情页事实）vs 该题材 **★首发消息时间戳**（原文地址页/接口的真实发布时间）。
- 判抢跑的两种情形：
  1. 首板日 < 首发消息日（日级先后，确定性抢跑，计算提前的交易日数 N）；
  2. 首板日 = 首发消息日，且消息发布于当日 15:00 收盘之后（当日涨停先于消息）。
- **不判**（避免误伤）：消息发布于盘前/盘中（属消息驱动行情）；题材标注"首发溯源待补"（窗口外）；封板时间与盘中消息先后不可核 → 标"时序待核"，不挂警示。
- **证据硬要求**：警示必须附证据对 `首板 YYYY-MM-DD（依据：K线/天梯）vs 首发 YYYY-MM-DD HH:MM（依据：原文地址）`，写入悬停提示或括号注；取不到首发时间戳的不得判。
- 一个题材多只抢跑标的时：题材级取最早首板计算提前天数，个股级各自标注。

**呈现（双层）：**

- 看板（HTML）：题材块头红色徽章 `⚠ 消息滞后·资金抢跑`（TIMELINE 块 `risk`/`riskNote` 字段）；个股行 `⚠ 抢跑` chip（STOCKS 块 `risk`/`riskNote`，悬停显示证据对）；★首发消息节点加红色 `消息晚于首板` 标签。
- Markdown 附录：题材挖掘行与标的行加 `⚠ 先涨停后消息（提前 N 个交易日）`，头部图例补一条。
- 统一文案：`⚠ 先涨停后消息（提前 N 个交易日）·疑似资金抢跑，兑现风险高，谨慎追高`。
