# 去重、排序、板块判定与股池映射规则

## 0. 双窗口股池与题材溯源

- **方向一·月度前七**（本月涨幅前七；剔 ST/退市/北交所/创/科板）：月度趋势主轴，**题材溯源以此为纲**。新口径不剔新股次新，次新标的可能上榜，如实呈现。月初窗口 total=0 属事实性空，**如实留空并以空态说明呈现，禁止用历史区间数据替代或补凑**（且不写历史库）。
- **方向二·近十日三强**（近十日涨幅前三；剔除同前）：近端强度确认，接口原生解析为 10 个交易日区间。盘中字段（竞价/换手）变化大，必须标注快照时间。
- **连板天梯**（全市场连板≥2 快照）：题材**溯源组件**而非独立股池；按月度前七的 F10 题材归组，含池外标的（灰字+悬停归属依据），无法归组的进"宏观·市场"未归组梯队。
- **★最强标识**：近十日三强 ∩ 月度前七 → 标"★最强"（双窗口确认：月度趋势与近十日加速度共振，最高关注级）；仅 d10 → "近十日新启动"；仅 month → "月度趋势延续"。
- **题材聚类**：以月度前七按 F10 行业×主营聚成题材组（如"固态电池×3"），连板梯队与消息时间链围绕该题材集合溯源。
- **新闻反查**：题材组关键词匹配要闻池（行业词+概念词，含第 3.9 步历史回溯补抓的消息），命中则关联新闻编号；无命中的组标注"无当日催化（题材轮动/资金驱动）"，可降级用韭研公社/开盘红搜主题帖佐证。
- **双窗交叉**：交集=★最强；仅方向二=新启动强势（关注趋势加速）；仅方向一=趋势延续无近端加速，写入"题材挖掘"小结。

## 1. 跨渠道去重

- 同一事件的判据：标题实体重叠（主体+动作）或指向同一政策/数据发布。
- 合并后：标题取信息最全的一条；渠道列合并标注全部命中来源；时间取最早。
- 同一事件同渠道的跟踪报道（如"30年美债升至5.595%"→"5.60%"）合并为一条，取最新数值。

## 2. 重要性排序（决定是否入简报、排第几）

事件层级从高到低：

1. 部委/国务院政策与官方发布（贴息、PSL、产业规划、部委发布会）
2. 宏观要闻（国内外大政策、贸易摩擦官方回应）
3. 行业级事件（行业规划落地、海外龙头大动作映射到 A 股行业）
4. 市场整体信号（指数、地量、板块大涨大跌）
5. 公司公告（控制权变更、大额定增/并购）

目标条数：**8 条左右，宁缺毋滥**（用户明确要求"只要重要的"）。海外纯行情/个股异动默认不入选，除非构成行业映射（如英伟达回购→PCB 链）。

## 3. 利好/利空板块判定

- 板块口径 = **东财行业（F10 核心题材三级行业，第 3.7 步产物）**，可附主营题材词（如 元件·PCB、电池·钠离子电池）。
- 判定依据写进板块行括号（一句因果），例：`券商（地量压制经纪与两融收入）`。
- 不是每条新闻都双向：无明确利空就写 `——`，不要硬凑。
- 判定要能落到池内标的才算"有效映射"，否则板块行标注`（股池内无相关行业标的）`。

## 4. 板块 → 池内标的映射

- **只映射池内标的**（月度前七 + 近十日三强去重后的 ≤10 只），禁止引入池外股票；题材溯源所需的连板梯队池外标的仅在 LADDER 天梯呈现，不参与消息面映射。
- 匹配顺序：新闻板块 == 标的 F10 行业 → 命中；其次标的 F10 主营关键词含相关题材词 → 命中并注明题材依据。
- 每个板块最多列 5 只，按本月涨幅降序。
- 标的行情格式固定：`**名称** ｜ 行业 ｜ 月度 +xx.x% ｜ 今日 +xx.xx% ｜ 竞价 +x.xx%`（数值来自选股器结果表，两位小数可保留一位简写）。

## 5. 消息面反向标注（股池表）

- 股池表"消息面"列：`<编号>·利好/利空（简注）`，如 `H·利好（PCB）`、`A·利好、D·利好（房贷贴息/地产大涨）`。
- 无关联标的写 `—`。
- 文末统计重叠度：`N 只中 M 只有当日消息面关联，其余为月度趋势延续、无当日催化`。

## 6. 官方性红线

- 三渠道均为 L2 权威媒体，正文只收 L2 及其转述的 L1 官方内容。
- 佐证源（韭研公社/开盘红）提升的条目必须在渠道行括号注明"开盘红、韭研公社热帖交叉佐证"。
- 每条新闻必须带真实采集到的原文 URL；禁止出现无出处的新闻。

## 7. 先涨停后消息（抢跑）高风险警示

部分标的在题材首发消息公布**之前**就已涨停（实例：2026-09 房地产——深物业A 9/28 首板，贴息政策 9/29 18:07 才发布）。资金先于消息抢跑，疑似消息提前泄露/知情资金进场，消息落地后利好兑现风险高，必须显式警示。

**判定（题材级 + 个股级，覆盖池内标的与天梯梯队员）：**

- 对照对象：该题材标的的**首板涨停日**（K 线/天梯/东财行情页事实）vs 该题材 **★首发消息时间戳**（原文地址页/接口的真实发布时间）。
- 判抢跑的两种情形：
  1. 首板日 < 首发消息日（日级先后，确定性抢跑，计算提前的交易日数 N）；
  2. 首板日 = 首发消息日，且消息发布于当日 15:00 收盘之后（当日涨停先于消息）。
- **不判**（避免误伤）：消息发布于盘前/盘中（属消息驱动行情）；题材标注"首发溯源待补"（窗口外）；封板时间与盘中消息先后不可核 → 标"时序待核"，不挂警示。
- **证据硬要求**：警示必须附证据对 `首板 YYYY-MM-DD（依据：K线/天梯）vs 首发 YYYY-MM-DD HH:MM（依据：原文地址）`，写入悬停提示或括号注；取不到首发时间戳的不得判。
- 一个题材多只抢跑标的时：题材级取最早首板计算提前天数，个股级各自标注。

**呈现（双层）：**

- 看板（HTML）：题材块头红色徽章 `⚠ 消息滞后·资金抢跑`（TIMELINE 块 `risk`/`riskNote` 字段）；个股行 `⚠ 抢跑` chip（STOCKS 块 `risk`/`riskNote`，悬停显示证据对）；★首发消息节点加红色 `消息晚于首板` 标签。
- Markdown 附录：题材挖掘行与标的行加 `⚠ 先涨停后消息（提前 N 个交易日）`，头部图例补一条。
- 统一文案：`⚠ 先涨停后消息（提前 N 个交易日）·疑似资金抢跑，兑现风险高，谨慎追高`。

## 8. 集合竞价异动标注

- **数据源**：选股器结果表"集合竞价涨跌幅"列（条件内"竞价涨幅大于-11%"非过滤性带出）。盘前执行为当日竞价值，盘中执行为当日快照值，随快照时间标注。
- **判定阈值**：竞价涨幅 ≥ +3% → 高开异动（红）；≤ -3% → 低开异动（绿）；其余不标。
- **呈现**：看板个股行"竞价 x.xx%"数值按涨跌着色，|值|≥3% 加粗+虚线下划+"竞价异动"角标（模板渲染内置）；POOLCHG 新进行竞价列同样高亮。Markdown 附录标的行竞价字段后加 `（高开异动）/（低开异动）`。
- **缺失如实**：竞价值缺失（"—"）如实标注，禁止估算；接口不提供竞价金额维度，不得虚构（"竞价金额大于0元"条件会过滤标的，禁用，见 SKILL.md 红线 3）。

## 9. 月度前七当月全景矩阵

- **矩阵结构**：表头=当月交易日（`MMDD+星期`，如 1014周三，今日列高亮）；行=排名 #1–#7；**配色三层信号**：题材=实心色签（vivid 底+白字，对比度≥4.5:1）+左侧 3px 题材色条（同题材同色系）；名次=当前前七标的按今日名次固定彩虹字（#1 红→#7 紫，跨列同色）并给极浅题材底；层级=其余历史格与移除行白底灰字+幽灵色签（vivid 描边/文字）；个股行名称与 `rk` 角标同用标的色；**交互：点击格子联动高亮同一标的（题材色描边）并弱化未命中格，点击名称跳行情页不拦截**；单元格=该日该排名的**标的（外链东财行情页）+题材+月度涨幅**；表尾灰色行=**较昨日移除标的**（历史轨迹格带当期排名，今日格"今日移除"标记）。
- **数据口径**：每列来自该交易日的前七快照；当日快照来自第 3 步结果，历史日由第 3.3 步区间措辞回补（接口自动收敛节假日）；同日重跑覆盖当日快照。矩阵按列读=当日前七，按行读=排名位次逐日易主（同一标的跨列同彩虹字色、同一题材同色签/色条）。
- **新进标注**：今日列中不在昨日前七集合内的标的带"新"角标（渲染自动判定，无需手工标）。
- **题材回填**：`themes`（代码→题材）映射由模型按 F10 核心题材填写，是矩阵单元格题材的唯一来源；缺失标"—"。
- **移出说明（可选）**：removed 条目的 `note` 按当日东财行情页事实标注"涨幅回落""被反超"等；无事实依据保持 null（渲染显示"—"），禁止估算。
- **首次运行**（baseline=true）：矩阵单列呈现，标"首次记录，无对比基线"。
- **历史库红线**：`archives/pool-history/month-top10.jsonl` 只存接口原始结果，禁止手工补写、修改或删除；回补只查缺失日期。**口径兼容**：2026-10-08～10-14 历史快照为前十口径（10 行），10-15 起为前七口径（7 行），矩阵与对比统一只取 rank≤7 子集，历史快照不迁移。
